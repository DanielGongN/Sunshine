# 启动显示模式

服务初始化显示管理器时，先恢复持久化显示状态，再对 output_name 指定的设备（空值沿用库的默认设备选择）应用 EnsureActive、1920×1080 和 60 Hz。不设置 HDR。

复用设置管理器保存与恢复状态；启动模式应用后，串流、断开和退出的现有配置与恢复入口不变。恢复时 API 暂时不可用则重试。旧拓扑无效或无法切换时，枚举当前主显示器，成功清除旧持久化状态后对当前主显示器应用启动模式；无主显示器时等待重试，清除失败则记录错误并停止启动设置。其他恢复错误停止启动设置。应用时仅 API 暂时不可用才重试，其他失败记录日志并继续服务。后续配置请求替换启动重试任务。

最终编译验证：在 MSYS2 UCRT64 执行 `bash build.sh`。实际显示模式切换需在交互桌面中另行确认。
